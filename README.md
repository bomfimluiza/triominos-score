# Triominos Score 📐✨
## Visão Geral
O Triominos Score é um assistente digital para o clássico jogo de tabuleiro Triominos. O objetivo principal é automatizar a contagem de pontos e o gerenciamento de partidas, substituindo o papel e caneta por uma interface moderna, intuitiva e temática.

## Principais Funcionalidades
- Gestão de Jogadores: Cadastro completo com nome, sobrenome e seleção de avatares personalizados em formato triangular.

- Marcador em Tempo Real: Fluxo de jogo dinâmico que alterna entre jogadores, permitindo a inserção de valores de peças, deduções por compra de peças e adição automática de bônus (Pontes, Hexágonos e Triângulos Duplos).

-Inteligência de Jogo: Guia de preparação que indica automaticamente quantas peças cada jogador deve comprar com base no número de participantes.

-Persistência de Dados: Histórico detalhado de partidas anteriores e um ranking global (Hall da Fama) para acompanhar os maiores pontuadores.

-Central de Regras: Consulta rápida às regras e pontuações especiais integrada ao aplicativo.

## Conceito Visual
O design é inspirado na identidade visual clássica do Triominos, utilizando uma paleta de cores em azul marinho, branco e dourado. A interface utiliza formas geométricas triangulares em botões, ícones e containers, reforçando a conexão temática com os componentes físicos do jogo.
